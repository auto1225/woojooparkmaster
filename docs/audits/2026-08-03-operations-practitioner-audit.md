# 운영관리 실무자 검증 보고서

- 검증일: 2026-08-03
- 사용자 관점: 제주시청 차량관리과 운영팀 주무관
- 대상: 운영현황, 인력, 위탁계약, 요금정책, 감면, 월정기권, 단속, 무료개방, 방치차량, 관제·보안점검
- 주차장 형태: 노외주차장, 주차빌딩, 노상주차장

## 발견 및 조치

1. 월정기권 갱신이 INSERT와 기존권 만료의 두 요청으로 분리되어 중복·부분실패 위험이 있었다. 멱등 원자적 `renew_monthly_pass` RPC와 활성권 부분 유일 인덱스로 교체했다.
2. 단속 납부가 한 번 클릭으로 상태만 변경되고 영수증 근거가 없었다. 영수증·수납문서·납부액·수납일을 필수로 받는 `mark_enforcement_paid` RPC와 감사 이벤트를 적용했다.
3. 단속 화면과 RPC 인자명이 달라 비고 호환 경로로 저장되는 문제를 실제 DB 조회로 발견했다. 전용 컬럼 계약으로 통일하고 기존 비고 증빙도 백필했다.
4. 위탁계약 성과점수는 실제 데이터가 100점 척도인데 초안 제약은 10점이었다. 화면과 DB를 0~100점으로 수정했다.
5. 요금정책 등록창의 저장 버튼이 720px 높이에서 화면 밖으로 밀렸다. 대화상자 최대 높이와 내부 스크롤을 적용했다.
6. 업무형 화면의 필수 날짜가 빈 값이라 모바일·자동입력 흐름을 막았다. 필수 날짜는 오늘, 처리기한은 7일 뒤로 기본 설정했다.
7. 방치차량·보안점검에서 주차장명을 자유입력하던 흐름을 주차장 원장 선택으로 교체하고 담당자 ID, 주차장 형태 스냅샷, 검토자, 문서번호를 보존했다.
8. 보관 기능이 사유 없이 호출되거나 잘못된 함수 인자를 사용했다. 보관 사유를 필수화하고 감사 가능한 보관 처리로 수정했다.
