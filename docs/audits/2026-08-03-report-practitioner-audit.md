# 보고서·통계 주무관 실사용 감사

- 감사일: 2026-08-03
- 사용자 관점: 제주시청 차량관리과 운영팀 주무관, 관리자
- 범위: 보고서 센터, 생성, 이력, 예약 생성, 대시보드, 성과 순위, 간부용 현황판, PDF·Excel, 문서대장 연계

## 실제 수행

1. 일일 운영 보고서를 PDF와 Excel로 생성하고 문서번호 `제주시청-차량관리과운영팀-2026-0803`으로 문서대장에 등록·연결했다.
2. 예산 집행 현황 보고서를 PDF와 Excel로 생성하고 예산 원천 7건, 주차장 116개소, 장비 251대, 유지보수 400건 등 데이터 범위를 생성 전에 확인했다.
3. 생성된 PDF를 다시 내려받아 5쪽 모두 렌더링하고 한글, 결재란, 문서번호, 표 명암과 실제 예산 내역을 확인했다.
4. 분기 예산 예약을 등록하고 이름을 수정한 뒤 수동 실행하여 실행 횟수가 0회에서 1회로 증가하는 것을 확인했다.
5. 모바일 이력 화면, 검색·정렬, 보관·삭제 제한, 문서 연결을 검증했다.
