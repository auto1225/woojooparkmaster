# 수입관리 실무자 검수 보고서

- 검수일: 2026-08-03
- 관점: 제주시청 차량관리과 운영팀 주무관, 팀장 검증자, 현장 모바일 사용자
- 대상: 수입 대시보드, 일별 수입, 월 마감, 위탁수입 대사, 수입 분석, 월간 수입 보고서, 문서대장 연계

## 실제 실행 시나리오

1. 노상주차장 `용담해안도로 공영주차장` 수입 347,500원을 입력·수정·검증했다.
2. 주차빌딩 `[검증] 제주시청 현장연계 주차빌딩 (수정 확인)` 수입 480,000원, 차량 164대, 감면 8건·32,000원을 입력하고 관리자 검증을 완료했다.
3. 위탁 주차빌딩 `동문시장 공영주차장`의 2026년 8월 대사 `RC-202608-01001`을 생성하고 `대기 → 검토중 → 일치`로 처리했다.
4. 검증 완료 수입 수정, 수입 원장 삭제, 대사 직접 상태 변경을 SQL로 시도해 모두 차단되는지 확인했다.
5. 문서 연결용 수입 UUID와 대사 UUID로 진입해 해당 읽기 전용 상세가 자동 개방되는지 확인했다.
6. 390×844 현장 단말에서 일별 수입과 대사가 표 대신 카드로 표시되는지 확인했다.
7. 수입 분석과 2026년 8월 월간 보고서를 실제로 열어 검증률, 결제수단, 감면, 주차장 형태가 표시되는지 확인했다.
