# 업무분장 실무 검증 및 개선 보고서

- 검증일: 2026-08-03
- 사용 관점: 제주시청 차량관리과 운영팀·시설팀 주무관
- 검증 범위: 업무분장 등록·조회·수정·후속 업무·인수인계·보관·복원·문서 연계·모바일
- 주차장 구분: 노외주차장, 주차빌딩, 노상주차장

## 1. 검증 에이전트 진단

실무자 검증 에이전트와 기획 검증 에이전트가 기존 화면과 실제 데이터를 독립적으로 점검했다. 기존 업무분장은 기준정보 테이블에 저장되어 실제 사용자 계정, 효력기간, 공식 문서, 주차장 형태, 인수인계 책임을 추적하기 어려웠다. 후속 업무 생성 시 제목·담당자·기한·문서번호를 다시 입력해야 했고, 사용자 정의 업무 분류는 빈 선택값으로 표시됐다. 보관 자료를 다시 조회하거나 복원하는 기능도 없었다.

우선 개선 항목은 다음과 같았다.

1. 실제 담당자와 대체 담당자를 지정하는 독립 책임 원장
2. 시행일·종료일·문서번호·변경 사유·동시 수정 방지
3. 노외·주차빌딩·노상 적용 범위와 모바일 현장업무 연결
4. 업무분장에서 후속 팀 업무로 값의 중복 입력 없는 전달
5. 보관 사유, 보관함, 복원 및 권한 일치
6. 모바일에서 긴 세부업무를 접고 핵심 책임부터 확인하는 카드

## 2. 구현 내용

### 책임 원장

- `team_duty_records`를 업무분장 전용 원장으로 추가했다.
- 실제 담당자·대체 담당자, 효력기간, 적용 주차장 형태, 공식 문서, 담당 상태, 인수인계 기한·내용, 변경 사유를 저장한다.
- `row_version`으로 다른 사용자나 모바일 기기의 동시 수정을 감지한다.
- 같은 팀의 같은 활성 업무영역 중복 등록을 차단한다.
- 관리자·매니저와 소속 팀 편집자의 권한을 화면과 RLS에서 일치시켰다.
- 기존 기준정보 15건을 활성 12건, 보관 3건으로 손실 없이 이관했다.

### 실무 화면

- 등록, 상세, 수정, 검색, 유형·상태·주차장 형태·담당자 필터, 다중 정렬을 제공한다.
- 노외주차장, 주차빌딩, 노상주차장 적용 범위를 복수 선택할 수 있다.
- 공식 문서를 선택하면 문서대장에서도 해당 업무분장을 근거문서로 역추적할 수 있다.
- 변경 시 변경 사유를 반드시 남기며 보관 사유를 입력한 뒤 보관함에서 복구할 수 있다.
- 모바일에서는 세부업무를 기본 접힘으로 표시해 담당자·상태·기한·주차장 형태를 먼저 확인한다.

### 후속 업무와 인수인계

- 업무 등록 버튼으로 유형, 팀, 사용자 정의 분류, 제목, 실제 담당자, 처리기한, 문서번호, 다음 조치, 원본 경로를 자동 전달한다.
- 단일 주차장 형태 업무는 노외·주차빌딩·노상 형태와 공통 사업장까지 자동 전달한다.
- 주차장 형태에 맞는 현장 입력항목을 즉시 표시한다.
- 실제 담당자와 인수 담당자의 동일인 선택을 차단한다.
- 인수 대상자·기한·인계 내용이 모두 있어야 요청할 수 있다.
- 현재 활성 사용자가 1명인 운영환경에서는 인수인계 버튼을 비활성화하고 시스템 설정에서 다른 사용자를 등록하도록 안내한다.

## 5. 운영 전 확인사항

활성 사용자 프로필이 현재 `auto0104` 1명뿐이므로 실제 서로 다른 사용자 간 인수인계를 완료할 수 없다. 기능은 동일인 선택과 불완전한 요청을 차단하며 정상 동작한다. 운영 개시 전 시스템 설정에서 운영팀·시설팀 담당자 계정을 등록하고, 이관된 활성 업무 12건의 실제 담당자와 근거 문서를 지정해야 한다.

모바일 앱 확장 시 현재의 사용자 FK, 주차장 형태, 원본 경로, 문서 링크, `row_version`을 그대로 사용해 오프라인 임시저장과 재연결 동기화를 추가할 수 있다.
