# 대시보드 운영업무 검수 보고서

- 검수일: 2026-08-03
- 환경: 로컬 개발 서버 및 실제 Supabase 연결 데이터
- 사용자 관점: 제주시청 차량관리과 운영팀 주무관, 시설 담당자, 관리자
- 대상: `/`, `/complaints`, `/facility/maintenance`, `/facility/equipment`, `/revenue/reconcile`, `/approvals`, `/lots`

## 진단

기존 대시보드는 집계 자체는 있었지만 실무자가 오늘 확인해야 할 미종결 업무, 자료 실패 여부, 주차장 형태별 범위와 상세 목록 이동 조건이 충분히 드러나지 않았다. 특히 요약용 `open`, `attention` 조건을 상세 화면이 해석하지 못해 대시보드 숫자와 도착 목록 숫자가 달라지는 연계 오류가 있었다.

## 구현 결과

- 첫 화면 상단에 `운영 업무 점검`을 배치하고 미종결 누적 기준과 조회 시각을 표시했다.
- 민원, 시설 작업, 이상 장비, 수입 예외, 전체 결재를 한 번에 확인하도록 구성했다.
- 노외, 주차빌딩, 노상, 기타·미지정 범위를 같은 화면에서 전환할 수 있게 했다.
- 수입 예외를 미검증, 누락일, 미해결 위탁 대사로 분해했다.
- 조회 실패를 0건으로 숨기지 않고 부분 실패로 표시하며 재조회할 수 있게 했다.
- 내 업무에 주차장 형태, 문서번호, 다음 행동, 긴급 사유를 보강했다.
- 정기점검 예정일을 대체 기한으로 쓰는 경우 기준을 명시하고 조사 승인에는 제출 후 3일 검토 기준을 적용했다.
- 요약 카드 이동 시 상세 화면이 같은 상태와 주차장 형태 필터를 해석하도록 연결했다.
- 오래된 React Query 캐시 구조와 충돌하지 않도록 대시보드 쿼리 키를 버전 변경하고 모든 배열을 방어적으로 정규화했다.

## 후속 항목

- 관리자 외 `manager`, `editor`, `viewer` 계정별 카드 노출과 이동 권한은 시스템 설정 메뉴의 권한 전수검수 단계에서 검증한다.
- 네이버 지도 키 미설정 안내와 최근 활동 상세 이동은 종합 현황 및 시스템 설정 메뉴 단계에서 함께 보완한다.
- 내 업무 전체 135건의 고급 검색과 유형별 정렬은 종합 현황의 통합 작업목록과 중복되지 않도록 다음 단계에서 결정한다.
