# 주차장 관리 주무관 검증 보고서

- 검증일: 2026-08-03
- 사용자 관점: 제주시청 차량관리과 운영팀 주무관
- 범위: `/lots`, 등록, 상세, 수정, 삭제 보호, 문서·민원·시설 연계, 모바일 사용성
- 기준 유형: 노외주차장, 주차빌딩, 노상주차장

## 실제 실행 증거

1. `[검증] 제주시청 현장연계 주차빌딩`을 코드 `JJP-VERIFY-0803`으로 실제 등록했다.
2. 주차빌딩 4층, 128면, 장애인 6면, 전기차 12면 등 구분 면수와 설비·통신 정보를 저장했다.
3. 수정 화면에서 노상과 주차빌딩을 왕복 선택해도 기존 입력이 유지되는지 확인하고, 명칭·총면수 130면·전기차 14면으로 실제 수정했다.
4. 공식 문서 `제주시청-차량관리과운영팀-2026-0803-현장연계01`을 실제 연결했다.
5. 상세에서 민원 접수로 이동해 주차장과 유형이 자동 지정되는 것을 확인했다.
6. 유지보수 화면으로 이동해 해당 주차장 필터가 URL과 화면에 적용되는 것을 확인했다.
7. 삭제를 열어 공식 문서 연결을 감지하고 `삭제 불가`로 차단하는 것을 확인했다.
8. 목록 검색, 유형 요약 필터, 주차면수·최근 수정일 정렬, 오름·내림차순, 초기화를 실행했다.
9. 검색·정렬 상태가 URL과 새로고침 후에도 유지되는 것을 확인했다.
10. 위도 91, 경도 181, 주차면수 -1 입력으로 저장이 차단되고 각 오류 문구가 표시되는 것을 확인했다.
11. `PM-REAL-002`의 열린 업무와 현황조사 탭에서 영문 상태가 한글로 표시되고 조사 연결 불일치 안내가 해소된 것을 확인했다.

## 발견 및 반영

### P0

- 라디오 선택이 화면에만 반영되고 폼 상태에는 반영되지 않아 주차빌딩 층수와 위탁업체 입력이 동작하지 않았다.
  - `setValue` 기반 제어형 입력으로 등록·수정 화면을 수정했다.
- 공식 문서가 연결된 주차장도 관련 데이터가 없는 것으로 판단해 물리 삭제가 가능했다.
  - 조사, 인력, 장비, 유지보수, 주차면, 수입, 민원, 입찰, 용역, 공식 문서를 검사한다.
  - 연결 데이터가 하나라도 있으면 UI에서 삭제를 금지한다.
  - DB 마이그레이션에서 `parking_lots` DELETE 정책을 제거했다.

### P1

- 목록 검색·필터·정렬·페이지를 URL에 저장해 상세 왕복, 새로고침, 공유가 가능하도록 했다.
- 코드, 명칭, 주소, 유형, 상태, 운영주체, 주차면수, 수정일 정렬과 방향 전환을 제공했다.
- 행정동, 면적, 장애인·전기차·경차·임산부·기타 전용면 입력과 합계 검증을 추가했다.
- 좌표 범위와 주차빌딩 최소 층수 검증을 추가했다.
- 민원 접수와 유지보수 이동 시 주차장 선택을 유지하도록 연결했다.
- 목록 행에 키보드 Enter/Space 상세 진입과 포커스 표시를 추가했다.
- 조사 원본이 없어도 연결된 진행 조사 목록을 표시하고, 유지보수·조사 상태를 한글화했다.
- 조회 실패와 검색 0건을 실제 빈 목록과 구분했다.

### 모바일

- 상세 상단 작업 버튼을 줄바꿈 가능하게 변경했다.
- 민원, 유지보수, 주차면 배치의 44px 빠른 작업 버튼을 추가했다.
- 등록·수정 저장 영역을 화면 하단 고정 44px 버튼으로 변경했다.
- 독립 검증에서 390px 목록·상세·등록·수정의 전체 페이지 가로 넘침이 없음을 확인했다.

## 잔여 위험

- Supabase CLI 인증 토큰이 없어 신규 마이그레이션을 원격 DB에 적용하지 못했다. 배포 파이프라인에서 반드시 적용해야 한다.
- 폐쇄·이관 이력을 입력하는 전용 UI와 승인 흐름은 후속 원장 생애주기 단위로 구현해야 한다.
- 조회자·편집자·관리자 역할별 비교는 현재 admin 테스트 계정만 있어 수행하지 못했다.
- 수정 중 이탈 경고, 긴 모바일 폼의 섹션 접기, 모든 라디오·체크박스의 44px 터치 영역은 추가 개선 대상이다.
- 공식 문서 저장소 이중화와 보고서의 기준일 스냅샷 문제는 문서대장·보고서 메뉴 검수에서 함께 정리해야 한다.
