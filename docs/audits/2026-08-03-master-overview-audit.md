## 발견 후 수정

1. 최근 30일 수입을 최신 30행으로 계산하던 오류를 실제 날짜 조건으로 수정했다.
2. 실시간 원장의 존재하지 않는 `id` 조회를 `lot_id`로 수정하고 자료 실패 출처를 표시했다.
3. 카드와 원장 수가 맞도록 운영관리 첫 탭에 115개 주차장 운영 원장을 추가했다.
4. 수입은 전체 300건과 최근 30일 2,626만원, 민원은 전체 38건과 미종결 25건을 분리 표시했다.
5. 모든 원장 쿼리 오류를 빈 데이터로 숨기지 않고 재시도 상태로 표시한다.
6. 50/100건 페이지 처리, 1·2차 정렬, 빈값 위치, 오류 재시도, 키보드 행 진입을 공통 적용했다.
7. 고정 도움말 버튼이 다음 페이지 버튼을 덮던 문제를 하단 안전 여백으로 수정했다.
8. 민원 유형·접수 채널과 장비·주차장 유형을 한글 배지로 표시했다.
9. `CMP-DEMO-0012`의 완료일 역전을 감지하고 음수 처리일수를 업무 수치에서 제외했다.
10. 공식 문서번호를 조사·시설·입찰·용역·민원 원장에 연결했다.
11. 주차장 형태에 `미지정` 조회를 추가하고 빈 연계 자료도 찾을 수 있게 했다.
12. `/master/:module` 라이선스 판별과 원장 내보내기 권한을 적용했다.

## 후속 메뉴에서 이어갈 항목

- 계약·수입·예산·신설·실시간·보고서 행이 정확한 원본 레코드를 강조하도록 각 대상 메뉴에서 딥링크를 구현한다.
- 담당자, 처리기한, 다음 행동은 각 업무의 책임 모델을 확정하는 해당 메뉴 단계에서 원장에 추가한다.
- 월정기권 종료일 기반 상태 자동 보정과 업무별 영문 코드 한글화는 운영관리 단계에서 검증한다.
- 비관리자 역할별 화면·내보내기 검증은 시스템 설정 단계에서 실제 테스트 계정으로 수행한다.
