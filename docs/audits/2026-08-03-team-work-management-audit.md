# 팀 업무관리 실무 검증 및 개선 보고서

- 검증일: 2026-08-03
- 사용 관점: 제주시청 차량관리과 운영팀·시설팀 담당 주무관
- 검증 범위: 팀 업무관리, 업무분장, 문서대장, 주차장, 시설 유지보수, 민원, 알림, 모바일 화면
- 주차장 구분: 노외주차장, 주차빌딩, 노상주차장

## 1. 에이전트 감사 결과

실무자 검증 에이전트는 기존 팀 업무가 코드 기준정보에 저장돼 있어 담당자 계정, 주차장 FK, 상태 이력, 문서 연결의 일관성이 약한 점을 가장 큰 위험으로 판단했다. 기존 표본 12건 중 7건은 처리기한이 없었고 담당자 값에 역할·전화번호가 섞여 있어 개인별 업무함과 모바일 동기화에 부적합했다.

기획 검증 에이전트는 다음을 필수 개선 항목으로 선정했다.

1. 독립 업무 원장과 상태 전이 규칙
2. 실제 계정 담당자·검토자·처리기한·보류 사유
3. 문서번호와 공식 문서 링크의 양방향 일관성
4. 민원·시설 원본 업무의 중복 없는 팀 업무 전환
5. 주차장 FK 및 노외·주차빌딩·노상 유형별 현장 정보
6. 담당자 알림, 내 업무함, 모바일 카드 화면
7. 보관 사유, 복구, 동시 수정 충돌 방지 및 권한 통제

## 2. 구현 내용

### 업무 원장과 데이터 무결성

- `team_work_records`를 실제 업무 원장으로 사용하도록 전환했다.
- 업무번호, 유형, 팀, 담당자 계정, 주차장 FK, 처리기한, 검토자, 다음 조치, 보류 사유, 문서번호, 원본 모듈과 원본 레코드를 저장한다.
- `row_version` 낙관적 잠금으로 다른 사용자나 모바일 기기의 동시 수정을 감지한다.
- 원본 업무별 활성 팀 업무 중복 생성을 DB 고유 인덱스로 차단한다.
- 접수→배정→처리중→검토→완료와 보류·재개 상태 전이를 DB 트리거와 프런트 양쪽에서 검증한다.
- 완료 시 업무 유형별 완료 근거를 요구한다.
- 보관은 삭제 대신 보관 사유를 남기며 복구할 수 있다.

### 실무 화면

- 6개 업무 유형별 등록·조회·수정·상태 처리·보관·복구를 제공한다.
- 상태, 팀, 우선순위, 주차장 형태, 주차장, 담당자, 문서 연결 여부 필터를 제공한다.
- 처리기한, 우선순위, 상태, 수정일, 문서번호, 업무번호, 제목, 주차장, 담당자, 금액 정렬을 제공한다.
- 주차장과 담당자를 검색 가능한 선택기로 변경했다.
- 상세 화면에서 주차장 상세와 원본 민원·시설 업무로 바로 이동할 수 있다.
- 관리자·매니저·편집자만 등록·수정·상태 변경·문서 연결·보관을 수행한다. 조회자는 읽기 전용이다.
- 업무분장은 모바일 카드에서도 기존 화면 이동, 새 업무 생성, 수정, 보관을 수행할 수 있다.

### 주차장 유형별 현장 정보

- 노외주차장: 구역·열·주차면, 포장·배수·차단기 상태
- 주차빌딩: 층·구역·설비 위치, 소방·승강기·환기 상태
- 노상주차장: 도로명·구간·면 번호, 교통안전·노면표시 상태

### 다른 기능과의 연계

- 민원 상세에서 주차장, 담당자, 기한, 원본 링크를 유지한 팀 업무를 생성한다.
- 시설 유지보수 상세에서 주차장, 담당자, 유형별 현장 정보, 원본 링크를 유지한 팀 업무를 생성한다.
- 시설 업무 기본 처리기한은 노상 2일, 주차빌딩 3일, 노외 5일 기준으로 제안한다.
- 같은 민원·시설 원본에서 중복 팀 업무 등록을 차단한다.
- 팀 업무를 내 업무함과 모바일 하단 메뉴에 연결했다.
- 담당 배정, 처리 시작, 검토 요청, 보류, 완료, 담당자·기한 변경 시 담당자 알림을 생성한다.
- 공식 문서 연결·해제 시 링크와 팀 업무의 문서번호를 함께 갱신한다.

- 민원과 시설 원본 링크가 양방향으로 이동했다.
- 같은 원본의 두 번째 업무 등록이 차단됐다.
- 문서 연결 해제 시 목록의 문서번호가 즉시 비워졌고 재연결 후 복구됐다.
- 민원 연계 업무를 실제 배정한 뒤 `TEAM_WORK` 알림과 업무 상세 링크가 DB에 생성됐다.

## 6. 후속 개선 우선순위

이번 범위에서 핵심 일상 업무는 사용할 수 있는 상태로 구현했다. 다음 항목은 별도 자동화 단계가 필요하다.

1. 반복 업무의 일정 기반 자동 생성과 휴일 보정
2. 실제 결재선의 검토자 계정·승인 기록 연결
3. 기한 임박·초과 배치 알림과 팀장 에스컬레이션
4. 사진 외 일반 첨부파일 분류, 버전, 삭제 권한
5. 모바일 오프라인 임시저장과 재연결 동기화 큐
6. 단일 주차장이 아닌 광역 업무의 다중 주차장 연결 모델
7. 기존 6건의 업무 범위와 기존 담당자 계정 수동 정비

이 항목들은 현재 데이터 모델의 `source`, `row_version`, 담당자 FK, 문서 링크를 기반으로 확장할 수 있다.
