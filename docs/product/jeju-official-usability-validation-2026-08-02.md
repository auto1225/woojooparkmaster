# 제주시 차량관리과 주무관 사용성 검증

- 검증 환경: 로컬 개발 서버와 데모 데이터
- 검증일: 2026-08-02 KST
- 대상 역할: 제주시청 차량관리과 운영팀 주무관, 시설 담당자, 팀장
- 주의: 데모 건수는 기능 검증용이며 실제 처리 성과의 기준선이 아니다.

## 검증 업무

1. 첫 화면에서 오늘, 지연, 긴급 업무를 찾는다.
2. 문서번호로 공문을 찾아 원문과 연결 업무를 확인한다.
3. 민원을 접수하고 담당자, 기한, 주차장 형태를 지정한다.
4. 시설 유지보수 목록에서 미배정·기한초과 작업을 찾고 상세 처리로 이동한다.
5. 모바일 화면에서 현장 업무와 사진 증빙 흐름을 확인한다.

## 현재 사용성 판정

- 업무 발견: 개선 후 적합. 첫 화면에서 오늘·지연·긴급을 바로 분리할 수 있다.
- 문서번호 조회: 적합. 검색 열기, 번호 입력, 결과 선택의 3단계로 상세에 도달한다.
- 민원 접수: 조건부 적합. 분류·주차장·기한·개인정보 동의·담당자 입력은 갖췄으나 접수 첨부파일은 별도 보강이 필요하다.
- 시설 유지보수: 개선 후 적합. 검색·주차장 형태·유형·상태·다중 정렬과 페이지 이동이 동작한다.
- 모바일 현장업무: 조건부 적합. 390px에서 가로 넘침 없이 카드 목록과 페이지 이동이 되지만 완전한 오프라인 사진 전송 큐는 후속 범위다.

## 운영 도입 전 필수 확인

1. 운영팀·시설팀·팀장 계정으로 각각 로그인해 역할별 메뉴와 수정 권한을 확인한다. 현재 검증 계정은 관리자다.
2. 네이버 지도 운영 키와 허용 도메인을 설정한다. 키가 없어도 비지도 업무는 계속 사용할 수 있다.
3. 발송·접수 완료 공문은 원문 파일을 필수 운영 규칙으로 정하고 기존 원문 누락 문서를 정비한다.
4. 민원 접수 사진·첨부와 모바일 오프라인 재전송 큐를 다음 배포 범위로 지정한다.
5. 실제 주무관 3~5명이 1주간 사용하며 업무 찾기 시간, 접수 입력시간, 재입력 횟수, 미배정·기한초과율을 측정한다.
