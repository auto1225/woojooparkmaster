# 보고서 센터 단계별 개편 기준

## 1단계 완료: 2025년 제주시 공영주차장 현황 통합보고서

- 대상: 제주시청 차량관리과 운영팀
- 기준정보: 2025년 현황조사 기준 공영주차장 112개소, 6,380면
- 검증자료: 2024년 1월부터 2025년 12월까지 월별 자료 2,688건
- 문서번호: `RPT-연도-순번` 형식의 짧은 관리번호와 관련 공문 문서번호를 함께 기록
- 원본: HWPX
- 배포본: 한컴오피스에서 HWPX 원본을 변환한 PDF
- 기본 용지: A4 세로, 필요할 때 A4 가로 선택
- 기본 글꼴: 맑은 고딕, 미설치 환경은 휴먼고딕 계열 대체

## 필수 구성

1. 보고 개요
2. 종합 현황
3. 전년 대비 분석
4. 주차장 유형별 현황
5. 월별 운영 추이
6. 민원·시설·안전 통합 분석
7. 중점관리 대상
8. 종합 분석 및 차년도 조치계획
9. 자료 산출 및 검증 기준

연간보고서는 단순 합계표가 아니다. 전년 대비 증감, 주차장 유형별 차이, 월별 추세, 민원 처리, 시설 장애, 안전 시정, 위험 주차장과 다음 연도 조치계획을 함께 제시한다.

## 생성 원칙

- 동일한 원천자료와 조건은 항상 동일한 결과를 생성한다.
- AI 연결은 필수 조건으로 두지 않는다. 집계와 판단 문구는 검증 가능한 규칙으로 생성한다.
- 시험자료는 실제자료와 혼동되지 않도록 자료구분과 생성 버전을 문서에 표시한다.
- 노외주차장, 주차빌딩, 노상주차장을 독립 집계하고 0건도 누락하지 않는다.
- 보고서 구성 변경은 사용자가 선택한 출력 항목을 임의로 초기화하지 않는다.
- 업무별 전체 선택과 보고서 전체 선택을 모두 제공한다.
- 생성 완료 후 결과 영역으로 자동 이동하고 PDF 보기, PDF 저장, HWPX 저장을 제공한다.
- 표는 페이지 폭을 넘지 않으며 제목만 페이지 하단에 고립되지 않게 묶는다.
- PDF와 HWPX는 동일한 HWPX 원본에서 파생해 서식 차이를 최소화한다.

## 순차 제작 순서

각 단계는 기획, 데이터 규칙, UI, HWPX, PDF, 자동검증, 육안검증을 완료한 뒤 다음 단계로 이동한다.

1. 일일 운영보고
2. 주간 운영보고
3. 월간 운영보고
4. 분기 운영보고
5. 시설관리 보고
6. 민원관리 보고
7. 수입·정산 보고
8. 예산관리 보고
9. 입찰·계약 보고
10. 용역사업 보고
11. 현황조사 보고
12. 주차장 통합 현황보고
13. 경영·간부 보고
14. 감사 대응 보고

## 단계별 완료 조건

- 실제 입력 또는 결정론적 시험자료로 생성 성공
- HWPX 압축 구조와 필수 문구 검증 통과
- 한컴오피스 PDF 변환 성공
- A4 세로와 가로의 표 잘림, 겹침, 고립 제목 없음
- 보고서 센터에서 조건 설정부터 파일 저장까지 한 흐름으로 완료
- 문서대장 연결에 필요한 관리번호와 관련 공문 문서번호 포함
- 데스크톱과 모바일 폭에서 선택·생성 동선이 유지됨
